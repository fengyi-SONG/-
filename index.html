数据与隐私

① 本地处理（默认，不联网）
你填写的全部内容、问答记录、作品集渲染、PDF 生成，都只在你本机浏览器里发生。没有后端，没有埋点，没有账号。
② 链接读取（只有你点「读取」时才发生）
目前只支持 GitHub 仓库，请求发往 api.github.com，内容是仓库的公开信息。 不会把你的链接发给任何第三方代理服务。
③ AI 增强（你填写 Key 并同意后才发生）
只有你主动点击润色时，才会把你提交的文本发到你自己填的接口地址。不经过本产品任何服务器。
⚠ 关于 API Key 的真实风险
纯前端架构下，Key 只能明文存在浏览器 localStorage 里。它不是安全的： 同源的任何脚本、浏览器扩展、以及和你共用这台电脑的人都能读到它。 建议用单独的低额度 Key，用完就点下面的删除。
④ 删数据
没有云端副本，所以删了就是真删。点击下方按钮会清空：作品集内容、问答记录、API Key。
